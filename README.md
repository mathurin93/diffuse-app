# Diffuse Digital Interview Study App

Single-page HTML + JavaScript + Tailwind study app for your second-round Shopify/SEO interview.

## Included
- 44 tailored interview questions
- Shopify, Liquid, Metaobjects, Metafields, APIs, JSON-LD, technical SEO, Core Web Vitals, accessibility, troubleshooting, agency scenarios, and behavioral questions
- Category filters and shuffle
- Reveal-answer flashcards
- "I Know This" / "Needs Review" tracking
- LocalStorage progress saving
- 90-second Interview Mode
- Practice-answer text area
- Keyboard shortcuts: Left/Right arrows, Space/Enter

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for the Pages URL.

No build step is needed. Tailwind loads from the CDN.
